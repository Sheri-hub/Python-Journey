# Python-Journey: Bioinformatics DNA Sequence Analysis
This repository contains my first Python project as a bioinformatics student, focusing on basic DNA sequence analysis.

Project Overview
The project demonstrates essential bioinformatics tasks including calculating GC content and finding specific motifs within a DNA sequence. It serves as a foundation for applying programming skills to biological data analysis.

Features
Installation and utilization of the Biopython package.
Definition and manipulation of example DNA sequences.
Calculation of GC content percentage in DNA.
Searching for specified nucleotide motifs and reporting their positions.

Tools Used
Python 3.x
Biopython library
Jupyter Notebook

How to Use
Clone the repository.
Open the Jupyter notebook file (.ipynb).
Execute cells to run the DNA analysis scripts.
Modify the DNA sequence or motif variables as desired.

Learning Outcomes
Understanding basic bioinformatics sequence operations.
Familiarity with Python scripting for biological data.
Experience with Jupyter notebook for interactive coding.
